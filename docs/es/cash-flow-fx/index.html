Conciliar el efectivo sin olvidar el efecto cambiario

Un ejemplo con signos, un dato cambiario explícito y una prueba que falla a propósito.

  1. Inicio
  2. Conciliar el efectivo sin olvidar el efecto cambiario

Por: faigvain-angPublicado: 2026-11-03 · Actualizado: 2026-11-04

Empiece por la definición de efectivo

El ejemplo sintético FY2025 usa millones de USD y el mismo perímetro de efectivo y equivalentes en ambos extremos. Antes de copiar cifras, compruebe si el informe concilia también efectivo restringido. Una definición distinta en el saldo inicial no se arregla con más precisión aritmética.

Descargue el repositorio, abra su directorio y utilice Python 3.11 o posterior. No necesita instalar paquetes.

git clone https://github.com/faigvain-ang/cashflow-bridge-check.git
cd cashflow-bridge-check
python cashflow_bridge.py examples/reconciled.json --json

Lea los signos, no solo los nombres

La muestra contiene saldo inicial 100, explotación 35, inversión -20, financiación -10, efecto cambiario -2 y cierre declarado 103. Los importes son cadenas decimales en JSON. La salida de inversión ya es negativa: restarla otra vez invierte su significado. La herramienta suma flujos netos con signo.

100 + 35 + (-20) + (-10) + (-2) = 103
calculated_closing: 103
reported_closing: 103
difference_reported_minus_calculated: 0
matches: true

Provoque una diferencia visible

Copie la muestra y cambie solo closing a "104". Ejecute el mismo comando sobre la copia: la diferencia pasa a 1, matches es false y el proceso termina con código 1. Una entrada inválida termina con código 2. Así se distingue un descuadre de un archivo mal formado.

El efecto cambiario es obligatorio. Introduzca "0" solo si la fuente lo respalda. Se permiten ajustes adicionales identificados, pero no una partida inventada para cuadrar el saldo.

Todas las cifras son sintéticas. Que cuadre la ecuación no demuestra calidad contable ni valor de inversión. Para seguir investigando con referencias a informes públicos, consulte Eqvero.
