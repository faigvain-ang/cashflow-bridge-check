ABOUT / MAINTENANCE

Quién mantiene este cuaderno

Este cuaderno y Cashflow Bridge Check se mantienen bajo faigvain-ang, por el mismo equipo que desarrolla herramientas del ecosistema de Eqvero, KolmoPDF y KomoPDF. Declaramos esa relación: estas páginas no son reseñas independientes.

Aquí comprobamos aritmética de información pública. Eqvero es el producto relacionado para investigar informes y comunicaciones empresariales con referencias a las fuentes. Este CLI no es un cliente de su API, una fuente de cotizaciones ni un motor de recomendaciones. Una conciliación que cuadra no garantiza que la fuente sea correcta.

Cómo funciona este sitio

Los artículos usan datos sintéticos. Este sitio educativo es estático: los comandos se ejecutan en su ordenador, no en el navegador. Las dependencias, si existen, se instalan por separado según el repositorio. Aquí no se cargan archivos ni hay analítica, fuentes externas, scripts CDN, backend o cuentas. Los servicios en la nube relacionados gestionan sus datos por separado.
