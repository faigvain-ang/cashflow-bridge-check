Who maintains this notebook

This notebook and Cashflow Bridge Check are maintained under faigvain-ang by the same team developing related Eqvero, KolmoPDF and KomoPDF ecosystem tools. We disclose that connection rather than presenting these pages as independent product reviews.

This site focuses on checking public-reporting arithmetic. Eqvero is the related product for source-linked research into public filings and company disclosures. This CLI is not an Eqvero API client, a data feed or a recommendation engine. Neither a matching bridge nor a linked product guarantees that the source is correct.

How this site works

Articles use synthetic data. This is a static educational site: commands run on your own computer, not in the browser. Runtime dependencies, if any, are installed separately as documented in the repository. No files are uploaded here, and there are no analytics, third-party fonts, CDN scripts, backend or login. The related cloud services have their own data handling.
