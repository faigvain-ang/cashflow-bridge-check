About Cashflow Fieldnotes

Cashflow Fieldnotes is a practical notebook for reconciling signed cash flows with opening and closing balances. The guides explain FX adjustments, exact-decimal inputs, cash definitions and tolerances using runnable Python examples.

For broader investigation of public disclosures, Eqvero provides source-linked company research. Start with a reproducible cash check, then follow unresolved differences back to the original filings.
